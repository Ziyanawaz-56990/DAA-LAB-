# Q1 — Put them in Order

## Objective
Implement the functions given in the DAA Lab-01 sheet in C and arrange them by increasing order of growth for sufficiently large values of `n`.

## Functions
1. `n log2(n)`
2. `12 sqrt(n)`
3. `1/n`
4. `n^(log2(n))`
5. `100n^2 + 6n`
6. `n^0.51`
7. `n^2 - 324`
8. `50n^0.5`
9. `2n^3`
10. `3^n`
11. `2^32 n`
12. `log2(n)`

## Method
The program calculates `log10(f(n))` rather than directly calculating extremely large function values. This prevents overflow for functions such as `3^n` and `n^(log2 n)` while preserving their numerical ordering.

The ranking is evaluated at the sufficiently large conceptual value `n = 10^1000`.

For the graph, the program also writes values for several logarithmically spaced values of `n`. The plot therefore shows the growth behaviour of the actual functions on a logarithmic scale rather than plotting only their final rank.

## Increasing order for sufficiently large n

```text
1/n
< log2(n)
< 12sqrt(n)
< 50n^0.5
< n^0.51
< n log2(n)
< 2^32 n
< n^2 - 324
< 100n^2 + 6n
< 2n^3
< n^(log2 n)
< 3^n
```

## Complexity
There are a fixed 12 functions, so sorting their computed comparison keys takes `O(12 log 12)`, which is `O(1)` with respect to `n`. The CSV generation uses a fixed number of sample points and functions, so it is also constant with respect to the mathematical input `n`.

## Files
- `q1_growth_order.c` — C implementation.
- `q1_growth_data.csv` — data generated by the C program for the growth plot.
- `q1_growth_order.csv` — final ranking generated by the C program.
- `plots/q1_growth_order.png` — logarithmic growth plot.
- `sample_output.txt` — sample terminal output.

## Build and Run

### Windows PowerShell
```powershell
gcc q1_growth_order.c -o q1_growth_order -lm
.\q1_growth_order.exe
```

### Linux/macOS
```bash
gcc q1_growth_order.c -o q1_growth_order -lm
./q1_growth_order
```

## Conclusion
The experiment shows that constant factors can affect numerical values for finite `n`, but the asymptotic order is determined by the dominant growth term. In particular, the large linear constant `2^32` does not make the function asymptotically quadratic, and `3^n` eventually dominates the polynomial and super-polynomial functions.
