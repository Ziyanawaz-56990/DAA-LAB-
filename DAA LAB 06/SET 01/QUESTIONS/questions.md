## Transcribed Questions (for text-searchability)

**1.** Write a program to find the nth Fibonacci number using Dynamic
Programming.

**2.** Implement the 0/1 Knapsack problem using Dynamic Programming.
Given n items with their weights and profits and a knapsack of capacity
W, determine the maximum profit that can be obtained. Analyze the time
and space complexity of your algorithm.

**3.** Implement the Longest Common Subsequence (LCS) algorithm using
Dynamic Programming. Given two strings, find the length of their
longest common subsequence and display the subsequence. Analyze the
complexity of the algorithm.

**4.** Write a program to implement Matrix Chain Multiplication using
Dynamic Programming. Given the dimensions of N-1 matrices in an array
`arr[]`, determine the minimum number of scalar multiplications required
to multiply the complete matrix chain.

```
Input:            N = 4
                  arr[] = {10, 30, 5, 60}

Output:           4500

Time Complexity:  O(N^3)
```
